Overview

EdiPro is an enterprise-grade X12 EDI parser and validator for healthcare transactions. It supports 837P, 837I, 835, and 834 transactions with strict HIPAA 5010 compliance rules.

  • Configuration-driven validation engine with YAML rule sets
  • 60+ built-in validation rules covering envelope, syntax, and business logic
  • In-memory processing with zero PHI persistence
  • OIDC bearer tokens and service account API keys
  • HIPAA X12 5010 compliant

Installation

Install the Python package using pip (Python 3.10+):

pip install -e .

Parsing EDI Files

Use the parse_edi_content() function to parse raw X12 content into structured representations:

from app.parser.x12_parser import parse_edi_content result = parse_edi_content(raw_x12_string) print(result.transaction_type) # "837P" print(len(result.segments)) # Segment count

Validation

Run validation against HIPAA 5010 standards:

from app.validation.rules import validate_edi_content validation = validate_edi_content(parsed_edi) print(validation.is_valid) # True / False for issue in validation.issues: print(f"[{issue.severity}] {issue.code}: {issue.message}")

REST API Endpoints

The FastAPI engine provides standard endpoints for transactions and health checks:

GET /api/health # Service liveness GET /api/health/detailed # Engine limits, rule counts, security mode GET /api/me # Identity and role POST /api/upload # Multipart file upload and validation POST /api/parse # JSON content parsing and rule validation POST /api/batch # ZIP archive batch processing
