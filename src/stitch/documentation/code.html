Overview

EdiPro is a modern, configuration-driven X12 EDI parser and validator for healthcare transactions. It supports the most common transaction types (837P, 837I, 835, 834) with optional LLM-powered plain-English explanations.

  • Configuration-driven rules via YAML files
  • 60+ built-in validation rules with plain-English messages
  • LLM-agnostic — works with any AI provider
  • Full Pydantic v2 type safety
  • HIPAA X12 5010 compliant

Installation

Install the Python package using pip:

pip install -e .

Or install from the project root. Requirements: Python 3.8+, pydantic ≥ 2.0, pyyaml ≥ 6.0.

Parsing EDI Files

Use the parse() function to convert any X12 EDI file into structured Python objects:

from validedi import parse result = parse('claim.edi') print(result.envelope.transaction_type) # "837" print(result.envelope.sender_id) print(len(result.loops)) # Hierarchical loop count

You can also pass an EDI string directly instead of a file path. The parser auto-detects transaction type from the GS/ST segments.

Validation

Run the validate() function to check 60+ rules across envelope, format, business logic, and code-set layers:

from validedi import validate result = validate('claim.edi') print(result.is_valid) # True / False print(result.error_count) # Number of errors for err in result.errors: print(f"[{err.severity}] {err.code}: {err.message}")

LLM Integration

Connect any LLM provider via a simple callable interface. The chatbot example uses Groq with Llama 3.3:

from groq import Groq from validedi.llm import explain client = Groq(api_key="your-key") def llm(prompt): return client.chat.completions.create( model="llama-3.3-70b-versatile", messages=[{"role":"user","content":prompt}] ).choices[0].message.content result = explain(edi_result, val_result, llm=llm) print(result.report)

REST API

The FastAPI backend exposes a single endpoint for file upload and validation:

POST /api/upload Content-Type: multipart/form-data Response: { "report": { "filename": "claim.edi", "parse_result": { "transaction_type": "837", ... }, "validation_result": { "is_valid": true, "issues": [] } } }

Start the backend with: uvicorn app.main:app --port 8000
