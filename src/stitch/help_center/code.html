quiz Frequently Asked Questions
What EDI transaction types does EdiPro support?expand_more
EdiPro supports 837P (Professional Claims), 837I (Institutional Claims), 835 (Remittance Advice), and 834 (Benefit Enrollment). Support for 270/271 eligibility and 276/277 claim status is planned for a future release.
How do I upload an EDI file?expand_more
Go to the Dashboard and drag and drop your .edi, .txt, .dat, or .x12 file into the upload zone, or click "Select Files" to browse. Files up to 256 MB are supported. The system will automatically detect the transaction type and run validation.
How does AI-powered parsing work?expand_more
EdiPro uses a Groq LLM (Llama 3.3 70B) to provide plain-English explanations of EDI validation errors, segment meanings, and actionable fix suggestions. The AI is provider-agnostic and can be swapped in Settings.
Is this HIPAA compliant?expand_more
Yes. EdiPro is built with HIPAA x12 5010 standards. All data is processed locally or within your secure infrastructure. We do not store PHI on third-party servers without your explicit consent and BAA signing.
What does a validation error mean?expand_more
Validation errors indicate that a segment or element does not conform to X12 5010 rules. Each error includes an error code (like CLM01_REQUIRED), a human-readable message, and a fix suggestion. Warnings are non-critical issues that may need attention.
